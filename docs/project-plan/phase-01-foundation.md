# 阶段 01：基础骨架

## 目标

建立后端 `fetchnews/` 与前端 `web/` 的最小可运行骨架，打通本地开发、依赖安装、基础配置、API 通信和目录边界。

## 子目标

### 后端骨架

- 建立 `FastAPI` 应用入口
- 建立配置系统、日志和数据库 session
- 建立基础模型目录和 schema 目录
- 建立 `Celery worker` 与 `beat` 入口

### 前端骨架

- 初始化 `React SPA`
- 配置 `Vite`、`TypeScript`、路由和基础状态管理
- 建立 API client 层
- 搭出最小 layout 与仪表盘占位页

### 工程化基础

- 建立 `.env` 约定
- 建立 Docker Compose 基础服务
- 建立前后端联调方式
- 明确 CORS、基础鉴权和环境配置策略

## 交付物

后端：

- FastAPI 应用可启动
- 健康检查接口
- 数据库初始化逻辑
- Celery 基础任务可启动

前端：

- React SPA 可启动
- 路由生效
- API client 能请求后端健康接口
- 基础控制台页面可渲染

## 完成标准

- 本地可一条命令拉起主要依赖服务
- 前端页面可请求后端 API
- 前后端目录职责清晰，彻底弃用模板后台路线

## 主要风险

- 前后端联调链路不通，阻塞后续所有阶段
- 配置项过早复杂化，抬高开发门槛

## 阶段出口

完成后进入 阶段 02，开始真实来源接入与原始事件入库。
