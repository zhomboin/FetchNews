# FetchNews 总体计划

## 总体目标

建设一套面向中文 AI 从业者的资讯聚合、内容审核与多平台分发系统。系统需要定时抓取高价值来源，完成标准化、去重、聚类、摘要、草稿生成、人工审核、定时发布与结果回写，并把发布后的反馈继续反哺选题、栏目与平台文案策略。

## 下一步优先级

1. 真实外部能力接入：真实发布器、真实采集连接器。
2. 智能能力增强：真实 LLM provider、embedding 去重与向量召回。
3. 编辑协作治理：块级 diff、编辑历史、权限与审计 UI。
4. 生产化部署：迁移、配置、监控、告警、备份与 Runbook。
