# Phase 03: 标准化、去重、聚类与评分

## 目标

把 `raw_items` 转换为统一结构的 `normalized_items`，并将同一事件的多来源内容聚合成 `stories`，减少重复与噪声。

## 子目标

### 标准化
- 统一标题、作者、发布时间、正文、链接字段
- 生成 canonical URL
- 清洗 HTML 和无效追踪参数
- 提取语言、标签和关键词

### 去重与聚类
- 基于 URL、标题相似度和来源关系进行聚类
- 合并重复转载和同源多次抓取结果
- 为每个聚类生成稳定的 story key

### 评分与排序
- 综合来源可信度、热度、时效和相关度
- 给 story 生成排序分值
- 支持后续日报选题时直接消费

## 交付物

- `normalized_items`
- `stories`
- 基础聚类服务
- 评分策略初版
- `GET /stories`

## 完成标准

- 同一事件的多来源内容能有效归并
- 明显重复内容不会在 story 列表中重复出现
- story 具备摘要前的结构化输入能力

## 主要风险

- 标题相似度阈值过松或过严
- 二次转载覆盖一手来源
- 评分规则过于简单导致选题噪声偏高

## 阶段出口

完成后进入 Phase 04，基于 `stories` 生成文章和短帖内容资产。
