# 阶段 02：来源接入与原始事件入库

## 目标

打通 P0 来源接入链路，让 GitHub、arXiv、官方 RSS / 博客和 X 白名单来源能够按计划抓取，并将结果以统一原始事件格式写入数据库。

## 子目标

### 来源目录与配置

- 建立来源注册表
- 为每类来源定义配置 schema
- 支持白名单、优先级和启用状态管理

### 抓取连接器

- GitHub 连接器
- arXiv 连接器
- RSS 连接器
- X 白名单连接器

### 原始数据层

- 定义 `sources` 与 `raw_items`
- 保存标题、正文、作者、链接、时间和平台元数据
- 记录抓取时间与采集状态

### 调度与失败处理

- 支持手动触发
- 支持定时任务
- 支持超时、失败、重试和错误记录

## 交付物

- 来源注册表
- 四类 P0 来源基础连接器
- `POST /ingest/run`
- 原始事件入库能力
- 采集日志与失败状态记录

## 完成标准

- 至少一批 P0 来源能稳定抓取
- 相同来源的原始事件能稳定入库且保持幂等
- 单个来源失败不会中断整批任务
- 可查询某次采集的结果与错误

## 主要风险

- 第三方页面结构变化
- X 接口权限和风控限制
- RSS 源不稳定或延迟较大

## 阶段出口

完成后进入 阶段 03，对原始事件做标准化、去重和聚类。
