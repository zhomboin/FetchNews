# 阶段 05：审核控制台与发布队列

## 目标

建立 React SPA 审核控制台，并打通平台发布队列，让运营能够对 story、草稿和短帖进行人工审核、编辑、预览和定时发布。

## 子目标

### React SPA 审核台

- 仪表盘概览
- story 列表与详情页
- 草稿预览与编辑
- 多平台短帖预览
- 发布队列与状态页

### 审核动作

- 审核通过 / 驳回 story
- 编辑标题与排序
- 调整文章结构和发布内容
- 记录人工操作日志

### 发布能力

- 创建发布任务
- 记录平台返回结果
- 失败任务重试
- 至少支持一个长文出口和一个短帖出口

## 交付物

- React 审核台关键页面
- `POST /stories/{id}/approve`
- `POST /articles/{id}/publish`
- `GET /publish-jobs`
- 发布重试接口

## 完成标准

- 运营可从 UI 完成“审核 -> 预览 -> 发布”的完整流程
- 发布失败不会丢失任务状态
- 所有发布动作具备审计记录

## 主要风险

- 平台接口限制较多
- 审核页过早做复杂，拖慢主流程落地
- 前端状态管理混乱影响稳定性

## 阶段出口

完成后进入 阶段 06，集中补齐质量、治理、运维和持续优化能力。
