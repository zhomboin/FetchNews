# Phase 00: 文档与决策基线

## 目标

在开始业务实现前，建立统一的项目边界、技术选型、来源范围和计划入口，避免后续在“做什么”和“怎么做”上反复返工。

## 范围

本阶段覆盖：
- 项目 README
- 协作约定文档
- 架构说明文档
- 来源清单文档
- 实施路线文档
- 总计划和分阶段计划文档

本阶段不覆盖：
- 业务代码实现
- API、数据库或前端页面开发

## 交付物

- 根目录入口文档
- `docs/architecture.md`
- `docs/content-sources.md`
- `docs/implementation-roadmap.md`
- `docs/project-plan/`

## 完成标准

- 团队成员可以只读文档就理解项目目标和范围
- 可以明确回答为什么使用 React SPA 而不是模板页或 Next.js
- 可以明确回答每个阶段做什么、不做什么、依赖什么

## 风险点

- 如果文档未及时同步，后续实现会偏离架构决策
- 如果阶段文档过于粗糙，执行时仍会不断回头补定义

## 后续衔接

完成本阶段后，直接进入 Phase 01，开始建立后端和前端骨架。
