# 阶段 00：文档与决策基线

## 目标

在开始业务实现前，建立统一的项目边界、技术选型、来源范围和计划入口，避免后续在“做什么”和“怎么做”上反复返工。

## 范围

本阶段覆盖：

- 项目 README
- 协作文档
- 架构说明
- 来源清单
- 实施路线
- 总体计划与分阶段计划

本阶段不覆盖：

- 业务代码实现
- API、数据库或前端页面开发

## 交付物

- 根目录入口文档
- `docs/architecture.md`
- `docs/content-sources.md`
- `docs/implementation-roadmap.md`
- `docs/project-plan/`

## 完成标准

- 团队成员只读文档就能理解项目目标和边界
- 能清楚说明为什么采用 `React SPA` 而不是模板后台或 `Next.js`
- 能清楚说明每个阶段做什么、不做什么、依赖什么

## 主要风险

- 文档与实现脱节
- 阶段文档过粗，执行时仍需频繁补决策

## 阶段出口

完成后进入 阶段 01，开始前后端基础骨架建设。
