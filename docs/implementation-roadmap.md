# FetchNews 实施路线图

## 目标

将现有系统从“内部可跑闭环”推进到“真实外部接入、智能内容增强、协作治理完善、生产化部署稳定”的阶段。路线图按小阶段拆分，避免把来源接入、内容智能、编辑协作和运维收敛混在同一轮实现。

## 当前状态

- Phase 00 - Phase 05：已完成
- Phase 06：进行中
- Phase 07 - Phase 10：已拆分为更细的后续阶段，见 [docs/project-plan/phase-07-future-roadmap.md](/D:/Code/Project/FetchNews/docs/project-plan/phase-07-future-roadmap.md)

## 当前重点

### 继续完成 Phase 06

- 补齐编辑工作台的版本 diff 可视化。
- 补齐编辑历史详情页与人工干预明细。
- 让来源治理、栏目势能和平台反馈更稳定地回流到排序与文案策略。
- 收敛前端测试挂起问题。

### 转入后续阶段时的顺序

1. 先做真实发布器和真实来源连接器。
2. 再接真实 LLM provider 与 embedding 能力。
3. 然后完善编辑协作治理。
4. 最后收敛生产化部署、监控与恢复流程。

## 约束

- 路线图中的任何阶段都必须能独立验收。
